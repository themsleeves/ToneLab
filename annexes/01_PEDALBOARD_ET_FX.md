# Pédales principales

## Fender The Pelt

Fuzz principale.

Contrôles :
- Level
- Tone
- Bloom
- Fuzz
- Mid switch
- Thick switch

Utilisation :
- Rythmique stoner
- Gros murs sonores
- Leads fuzz

Points d'attention :
Les réglages adaptés au rythme ne sont pas forcément idéaux pour les leads.

Solutions envisagées :
- Utilisation EQ après fuzz
- Réglage Mid/Thick
- Boost avec Tube Screamer

# Tube Screamer

Modèle :
Analogman Silver Mod

Réglage de référence :

Drive :
9h

Tone :
11h

Level :
14h

Rôle :
- Booster l'ampli
- Resserrer les graves
- Ajouter des médiums
- Améliorer l'attaque

# EQ

Modèle principal :
MXR 6 Band EQ

Fréquences :
- 100 Hz
- 200 Hz
- 400 Hz
- 800 Hz
- 1.6 kHz
- 3.2 kHz

Utilisation :
- Sculpture du son
- Adaptation entre guitares
- Correction fuzz

Réflexion :
Possibilité d'ajouter un second EQ pour garder un réglage par guitare.

Point d'attention :
Limiter l'ajout de bruit.

Alternative étudiée :
Mooer Graphic G.

# Reverb

Besoin :
- Hall
- Shimmer
- Reverse
- Ambiant

Non recherché :
- Spring (déjà disponible via ampli)

Expériences :

## Flamma FS02

Achetée d'occasion.

Avis :
- Sons jugés peu naturels
- Bruit parasite constaté avec saturation active

Symptôme :
Bourdonnement grave lorsque la pédale est activée.
