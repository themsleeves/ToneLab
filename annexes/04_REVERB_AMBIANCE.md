# Sous-agent — REVERB / AMBIANCE

## Mission
Choisir et exploiter une reverb complémentaire à la HOF Mini et au Brunetti.

## Besoin utilisateur
L'utilisateur ne cherche PAS une nouvelle Spring principale.

Il possède déjà :
- TC Electronic Hall of Fame Mini dans la boucle, réglée en Plate pour une profondeur légère.

La nouvelle reverb doit surtout apporter :
- Hall ;
- Shimmer / ambiance ;
- éventuellement Reverse ;
- textures spectaculaires ;
- plusieurs réglages/presets si possible ;
- qualité nettement supérieure à une petite Amuzik Ocean.

Budget de référence :
**maximum ~70 € d'occasion**, idéalement moins.

## Mooer A7
La Mooer A7 est une référence importante pour le besoin ambient.

Données constructeur vérifiées :
- 7 types de reverb ;
- fonctions Infinite Trail et Trail On ;
- buffer bypass ou true bypass ;
- un preset mémorisable pour chaque effet ;
- alimentation 9 V DC ;
- consommation **200 mA**.

Source : Mooer.

## Son rôle dans le rig
Elle peut fournir :
- Hall plus large ;
- ambiance ;
- textures modulées ;
- contraste avec la HOF Mini.

Elle n'a pas besoin de remplacer la HOF Mini : les deux peuvent avoir des rôles différents.

## Placement
À tester en priorité dans la boucle avec le delay, surtout pour les ambiances très longues :
**Send → Delay → A7 → Return**

Mais l'ordre doit rester une recommandation expérimentale, pas une vérité absolue.

## Philosophie de comparaison
Toujours distinguer :
- qualité sonore ;
- nombre/types d'algorithmes ;
- mémoires ;
- ergonomie live ;
- taille ;
- prix d'occasion ;
- bruit/fiabilité.

Ne jamais déclarer qu'une pédale est « meilleure » sans préciser selon quel critère.
