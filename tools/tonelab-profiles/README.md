# ToneLab Profiles

Version 0.2.0 — application mobile-first pour documenter les essais de profils sonores ToneLab.

## Fonctionnalités
- interface responsive smartphone/tablette/ordinateur ;
- listes déroulantes pour artistes, guitares, accordages, micros, statuts, canaux et cabinets ;
- cases à cocher pour les fonctions ON/OFF ;
- valeurs de réglage par pas de 0,5 ;
- Mooer Graphic G 5 bandes ;
- Thiele + Celestion 15 pouces 4 Ω ;
- sauvegarde locale dans le navigateur ;
- export Markdown d'un profil ;
- export JSON de l'ensemble des profils.

## Installation
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```
