# Chapitre 01 — Architecture du Brunetti XL R-EVO II

> *Cette section documente l'architecture et l'organisation du Brunetti XL R-EVO II. Elle constitue la référence technique permettant de comprendre comment l'amplificateur est organisé avant d'aborder l'étude détaillée des canaux, des réglages et de son exploitation sonore.*

# Objectif du chapitre

L'objectif de ce chapitre est de documenter **la structure du Brunetti XL R-EVO II** de manière suffisamment précise pour servir de référence à toute la suite du ToneLab.

Il ne s'agit pas encore de rechercher des réglages pour obtenir un son particulier.

Nous cherchons d'abord à comprendre :

- comment l'amplificateur est organisé ;
- comment ses trois canaux sont structurés ;
- quelles commandes appartiennent à chaque canal ;
- quelles commandes sont communes ;
- comment s'organise la chaîne de signal ;
- quelle place occupe la boucle d'effets ;
- comment les différentes sections de l'amplificateur interagissent.

Cette séparation est importante.

Les chapitres suivants pourront ainsi s'appuyer sur cette architecture sans avoir à réexpliquer continuellement le fonctionnement de l'amplificateur.

---

# Périmètre

Ce chapitre est consacré à **l'architecture et au fonctionnement général** du Brunetti XL R-EVO II.

Il doit être distingué des chapitres consacrés :

- aux caractéristiques sonores des différents canaux ;
- aux réglages pratiques ;
- aux associations avec les pédales ;
- aux profils sonores ;
- aux expérimentations.

Lorsqu'une information concerne principalement la manière de régler l'amplificateur pour obtenir une couleur sonore particulière, elle sera renvoyée vers les chapitres appropriés.

# Méthode documentaire

Comme pour le reste du ToneLab, les informations seront classées selon leur niveau de certitude.

### ✔ Confirmé

Information directement documentée ou suffisamment établie.

### ◐ Hypothèse solide

Interprétation cohérente avec les informations disponibles mais qui doit encore être vérifiée.

### 🧪 À vérifier

Information nécessitant une vérification sur le matériel ou dans une documentation technique fiable.

Cette distinction est particulièrement importante pour l'architecture interne.

Nous éviterons ainsi de présenter comme un fait une déduction faite uniquement à partir du comportement sonore de l'amplificateur.
