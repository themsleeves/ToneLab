# Introduction

Après avoir étudié les territoires Marshall et Mesa Boogie, nous abordons maintenant une famille d'amplificateurs dont la philosophie sonore est sensiblement différente.

Le territoire Diezel est particulièrement intéressant pour ToneLab parce qu'il permet d'étudier une autre manière d'obtenir un son puissant et fortement saturé.

L'objectif n'est plus uniquement de rechercher :

- du gain ;
- de l'épaisseur ;
- du volume ;
- de la saturation.

Il faut également rechercher :

- de la précision ;
- de la définition ;
- de la régularité ;
- du contrôle ;
- une attaque lisible.

Cette approche est particulièrement intéressante pour déterminer jusqu'où le Brunetti peut être orienté vers un comportement plus moderne sans perdre son caractère propre.

---

# Que signifie réellement « son Diezel » ?

Comme pour Marshall et Mesa Boogie, le terme « Diezel » désigne plusieurs amplificateurs et plusieurs comportements.

Les références les plus connues comprennent notamment :

- VH4 ;
- Herbert ;
- Einstein.

Le territoire qui nous intéresse dans ToneLab correspond principalement à l'image sonore associée aux amplificateurs Diezel modernes :

- saturation importante ;
- précision ;
- graves contrôlés ;
- attaque ferme ;
- grande définition ;
- forte capacité à conserver la lisibilité.

Il ne s'agit donc pas de chercher à reproduire un modèle Diezel particulier note pour note.

La recherche porte sur les **caractéristiques perceptibles** qui permettent d'entrer dans cette famille sonore.

---

# La philosophie sonore Diezel

La philosophie Diezel peut être résumée autour d'une idée :

> **obtenir beaucoup de puissance sans sacrifier la définition.**

Cette approche produit un comportement différent de celui que l'on peut rechercher avec un son plus lâche ou plus vintage.

Le son doit pouvoir rester lisible lorsque :

- le Gain augmente ;
- les graves deviennent importants ;
- plusieurs notes sont jouées simultanément ;
- les palm-mutes sont fortement accentués.

Cette exigence de contrôle explique pourquoi les amplificateurs Diezel sont souvent associés à des sons modernes et précis.

---

# Les principales caractéristiques du territoire Diezel

## Précision

La précision est probablement le critère principal.

Les notes doivent rester clairement séparées.

Un accord saturé ne doit pas devenir une masse indistincte.

Cette caractéristique dépend notamment :

- du niveau de Gain ;
- du grave ;
- des médiums ;
- de l'attaque ;
- du cabinet ;
- du réglage de la guitare.

---

## Définition

La définition est proche de la précision mais ne signifie pas exactement la même chose.

Un son défini permet d'entendre :

- les différentes notes ;
- l'attaque ;
- les variations du jeu ;
- les changements d'accords.

Un son peut être très saturé tout en conservant une bonne définition.

---

## Grave contrôlé

Le grave doit être présent mais fermement tenu.

Un excès de grave peut provoquer :

- flou ;
- perte d'attaque ;
- manque de séparation ;
- sensation de lenteur.

La maîtrise du grave constitue donc une priorité.

---

## Attaque ferme

L'attaque doit rester clairement perceptible.

Cela permet notamment :

- aux riffs de rester lisibles ;
- aux palm-mutes d'être précis ;
- aux rythmiques rapides de conserver leur définition.

---

## Saturation dense

Le territoire Diezel ne signifie pas nécessairement moins de Gain.

Au contraire, il est possible d'obtenir une quantité importante de saturation.

La différence réside dans la capacité à conserver la définition malgré cette saturation.

---

# Le Brunetti face au territoire Diezel

Le Brunetti peut rejoindre certaines de ces caractéristiques.

Le XLead est particulièrement intéressant dans ce contexte.

Son comportement permet de rechercher :

- gain important ;
- saturation dense ;
- attaque ;
- précision ;
- présence ;
- grave contrôlé.

Cependant, il existe une différence importante.

Le Brunetti n'est pas conçu autour de la même philosophie qu'un Diezel.

Il peut donc être orienté vers certaines caractéristiques du territoire Diezel sans devenir un véritable Diezel.

Cette distinction doit rester présente dans toute l'analyse.

---

# Le rôle du canal XLead

Le XLead constitue actuellement le meilleur point de départ pour explorer le territoire Diezel.

Cette conclusion repose principalement sur sa capacité à produire :

- une saturation importante ;
- une attaque ferme ;
- une réponse plus moderne ;
- une forte densité ;
- une bonne capacité de contrôle grâce aux réglages de voicing.

Le XLead est donc particulièrement intéressant lorsque l'objectif est :

> **un son fortement saturé mais restant précis.**

Cette orientation sera particulièrement utile pour les futurs profils recherchant :

- rock moderne ;
- metal léger ou intermédiaire ;
- rythmiques lourdes ;
- sons fortement articulés.

---

# Le rôle du canal Boost

Le Boost n'est pas totalement exclu.

Mais son rôle est différent.

Son caractère plus dynamique et plus riche en harmoniques peut être intéressant lorsque l'on recherche :

- davantage d'ouverture ;
- davantage de réaction au jeu ;
- moins de compression ;
- un caractère plus organique.

Il est cependant moins évident comme point de départ pour une reproduction du territoire Diezel.

La priorité reste donc :

**XLead → territoire Diezel**

et non :

**Boost → territoire Diezel**

Le Boost pourra éventuellement servir de point de comparaison dans les expérimentations, mais il ne constitue pas aujourd'hui une hypothèse centrale.

**Statut : 🧪 comparaison secondaire.**

---

# Boost et XLead : une différence de philosophie

La comparaison entre les deux canaux permet de faire apparaître une distinction intéressante.

## Boost

Tendance recherchée :

- dynamique ;
- épaisseur ;
- grain ;
- interaction avec le jeu ;
- saturation plus organique.

## XLead

Tendance recherchée :

- précision ;
- densité ;
- attaque ;
- contrôle ;
- saturation moderne.

Cette différence explique pourquoi le XLead est naturellement plus pertinent pour le territoire Diezel.

Le but n'est pas de rendre le Boost identique au XLead.

Il faut conserver les différences de comportement entre les canaux.

---

# L'importance de la précision

Pour rechercher le territoire Diezel, la précision doit être évaluée directement avec le jeu réel.

Un réglage peut sembler extrêmement précis lorsque les cordes sont jouées seules.

Mais cette impression peut disparaître lorsque :

- plusieurs notes sont jouées ;
- les palm-mutes sont utilisés ;
- le volume augmente ;
- une seconde guitare entre dans le mix.

Les essais ToneLab devront donc être réalisés avec des riffs représentatifs du style recherché.

---

# L'importance de l'attaque

L'attaque constitue un deuxième critère fondamental.

Elle permet de distinguer :

- un son saturé mais flou ;
- d'un son saturé et précis.

Le réglage d'attaque dépend notamment :

- de Edge ;
- de Focus ;
- du Gain ;
- de la guitare ;
- des micros ;
- du cabinet.

L'attaque doit donc être évaluée comme un résultat global plutôt que comme une conséquence d'un seul bouton.

---

# Le contrôle du grave

Le contrôle du grave est probablement l'une des principales différences perceptibles entre un son moderne précis et un son saturé plus lâche.

Une première approche consiste à régler le grave suffisamment bas pour conserver la précision.

Il est ensuite possible de reconstruire la sensation de poids grâce à :

- Depth ;
- le cabinet ;
- les haut-parleurs ;
- l'égalisation.

Cette méthode permet d'éviter d'utiliser Bass comme unique source de puissance.

---

# Influence du Gain

Le Gain doit être suffisamment élevé pour produire la saturation recherchée.

Mais un excès de Gain peut diminuer la précision.

Lorsque le Gain augmente :

- la compression augmente ;
- les harmoniques se multiplient ;
- l'attaque peut devenir moins distincte ;
- les graves peuvent devenir plus difficiles à contrôler.

Il faudra donc rechercher le **minimum de Gain permettant d'obtenir la saturation réellement nécessaire**.

Cette approche est particulièrement importante pour le territoire Diezel.

---

# Influence des médiums

Les médiums permettent de maintenir la présence des notes.

Un son moderne extrêmement creusé peut sembler impressionnant seul.

Mais il peut devenir difficile à entendre dans un mix.

Les médiums doivent donc être utilisés pour conserver :

- définition ;
- présence ;
- attaque ;
- séparation.

Le réglage recherché dépendra cependant du cabinet et de la guitare.

---

# Influence de Edge

Edge intervient fortement dans la perception de l'attaque.

Un Edge trop faible peut donner :

- un son sombre ;
- une attaque réduite ;
- une sensation moins précise.

Un Edge trop élevé peut produire :

- agressivité excessive ;
- dureté ;
- fatigue auditive.

Le bon réglage se situe donc dans une zone permettant d'obtenir une attaque nette sans transformer le son en source de fréquences aiguës agressives.

---

# Influence de Focus

Focus est particulièrement important dans cette recherche.

Il peut contribuer à modifier :

- la fermeté ;
- la précision ;
- l'attaque ;
- la sensation de contrôle.

Pour le territoire Diezel, il sera particulièrement intéressant de comparer plusieurs positions de Focus à niveau de Gain constant.

L'objectif sera de déterminer si Focus permet effectivement de rapprocher le Brunetti de la sensation de contrôle recherchée.

---

# Influence de Depth

Depth doit être utilisé avec prudence.

Une augmentation peut apporter :

- profondeur ;
- puissance ;
- sensation de grave ;
- ampleur.

Mais un excès peut réduire la précision.

Une bonne méthode consiste donc à :

1. régler d'abord Bass ;
2. obtenir un grave équilibré ;
3. régler ensuite Depth ;
4. vérifier la précision avec le jeu réel.

Cette méthode permet d'éviter d'obtenir un son puissant mais difficile à contrôler.

---

# La dynamique

Le territoire Diezel ne signifie pas nécessairement une absence de dynamique.

La dynamique doit simplement rester compatible avec la précision recherchée.

Un son trop compressé peut devenir :

- plat ;
- moins réactif ;
- moins expressif.

Un son trop dynamique peut au contraire devenir difficile à contrôler avec une saturation importante.

L'objectif est donc de trouver un équilibre.

---

# Le rôle de la guitare

La guitare influence directement la précision.

## Gibson Les Paul Classic DC

La Gibson apporte généralement :

- densité ;
- épaisseur ;
- médiums ;
- sustain.

Cette combinaison peut être intéressante pour les sons lourds.

Mais elle peut également produire davantage d'accumulation dans les bas-médiums.

Le réglage du Gain et du grave devra donc être surveillé.

---

## Gretsch John Gourley Broadkaster

La Gretsch peut favoriser :

- attaque ;
- séparation ;
- articulation ;
- dynamique.

Elle peut donc être intéressante lorsque l'objectif est de conserver une grande définition avec un niveau de saturation important.

La comparaison Gibson / Gretsch devra être particulièrement intéressante dans ce territoire.

---

# Le rôle de la Tube Screamer

La Tube Screamer peut jouer un rôle important dans la recherche de précision.

Son utilisation peut notamment :

- resserrer le grave ;
- augmenter les médiums ;
- accentuer l'attaque ;
- pousser le préamplificateur.

Cette combinaison peut être particulièrement intéressante avec le XLead.

Elle peut cependant modifier fortement le caractère du Brunetti.

Il faudra donc conserver deux familles de tests :

### XLead seul

Permet de déterminer le comportement propre du canal.

### XLead + Tube Screamer

Permet d'étudier une approche plus resserrée et plus agressive.

Cette distinction sera importante pour les futurs profils.

---

# Le rôle de l'égalisation

L'EQ peut être utilisée pour améliorer la définition.

Elle pourra notamment servir à :

- réduire les graves inutiles ;
- contrôler les bas-médiums ;
- renforcer les fréquences de présence ;
- adapter la réponse à la guitare.

Le Mooer Graphic G 5 bandes pourra être particulièrement intéressant dans ce contexte.

Cependant, l'EQ ne doit pas remplacer un réglage correct du Brunetti.

La méthode devra rester :

**amplificateur → guitare → pédale → EQ → validation.**

---

# Le rôle du cabinet

Le cabinet influence fortement la précision.

Un haut-parleur produisant beaucoup de grave ou une forte résonance peut rendre plus difficile l'obtention d'un son très contrôlé.

Le 4×12 de référence constitue donc un élément essentiel des essais.

Les différentes configurations de haut-parleurs présentes dans ce cabinet devront être considérées comme des configurations distinctes.

Le Thiele équipé du Celestion 15 pouces devra également être considéré séparément.

Il ne faudra pas comparer directement deux profils sans noter la configuration de cabinet utilisée.

---

# Différence entre territoire Diezel et territoire Mesa

Cette distinction est particulièrement importante.

Les deux territoires peuvent utiliser :

- beaucoup de Gain ;
- une forte saturation ;
- des graves importants ;
- une grande puissance.

Mais leur comportement recherché n'est pas exactement le même.

## Mesa / Rectifier

Tendance :

- ampleur ;
- largeur ;
- densité ;
- agressivité ;
- sensation de puissance.

## Diezel

Tendance :

- précision ;
- contrôle ;
- attaque ;
- définition ;
- grave maîtrisé.

Cette distinction nous permettra de construire deux profils fortement saturés sans simplement augmenter ou diminuer le Gain.

# Ce que nous retenons

Le territoire Diezel représente principalement une **recherche de contrôle**.

Le Brunetti peut s'en rapprocher en travaillant simultanément :

- Gain ;
- Bass ;
- Mid ;
- Edge ;
- Focus ;
- Depth ;
- guitare ;
- pédales ;
- cabinet.

Le XLead constitue actuellement le meilleur point de départ.

Le Boost reste intéressant comme point de comparaison, mais son intérêt principal se situe davantage dans :

- la dynamique ;
- le grain ;
- l'épaisseur ;
- la réaction au jeu.

Il ne constitue donc pas aujourd'hui le candidat principal pour ce territoire.

---

# Conclusion

Le rapprochement entre le Brunetti et Diezel repose principalement sur la capacité du Brunetti à produire un son :

- dense ;
- précis ;
- agressif ;
- fortement saturé ;
- mais suffisamment contrôlé.

Le XLead constitue la meilleure base pour explorer cette zone.

Cependant, obtenir cette sensation ne dépend pas uniquement du canal.

Le résultat dépend de l'équilibre global entre :

**Gain → Bass → Mid → Edge → Focus → Depth**

auquel viennent s'ajouter :

**guitare → Tube Screamer → EQ → cabinet**

Cette approche permet de comprendre pourquoi un simple réglage de Gain ne suffit pas pour construire un véritable profil sonore.

Le territoire Diezel doit être considéré comme une **combinaison de comportements**, et non comme une position particulière sur le potentiomètre de saturation.

Pour ToneLab, cette analyse aura surtout une conséquence importante :

> **un son fortement saturé n'est pas nécessairement un son massif ; il peut également être défini, précis et contrôlé.**

Cette distinction sera essentielle lorsque nous construirons les profils sonores du chapitre suivant.
