# Chapitre 02

# Partie 5 — Le territoire EVH

> *Le Brunetti XL R-EVO II est parfois décrit par ses utilisateurs comme capable de produire des sonorités proches de certains amplificateurs EVH. Cette comparaison est moins fréquente que celle avec Mesa Boogie ou Marshall, mais elle mérite d'être étudiée. Le but de cette partie est de comprendre ce qui rapproche réellement ces deux univers et comment exploiter cette proximité dans le cadre du ToneLab.*
> *Le territoire EVH constitue une zone particulièrement intéressante pour le Brunetti XL R-EVO II : suffisamment saturée pour exploiter le potentiel du XLead, mais suffisamment dynamique pour rendre le comportement du Boost particulièrement pertinent.*

# Introduction

Le territoire EVH occupe une position particulière dans la cartographie sonore du ToneLab.

Il ne correspond ni exactement au territoire Marshall traditionnel, ni au territoire Mesa Boogie fortement saturé, ni au territoire Diezel orienté vers la précision moderne.

Il se situe dans une zone intermédiaire particulièrement intéressante.

On recherche notamment :

- de la saturation ;
- de l'attaque ;
- de la dynamique ;
- des médiums ;
- de l'épaisseur ;
- mais également une certaine ouverture.

Cette combinaison en fait un territoire particulièrement intéressant pour comparer les canaux **Boost** et **XLead**.

---

# Que signifie réellement « son EVH » ?

Comme pour les autres territoires étudiés dans ce chapitre, le terme « EVH » ne doit pas être interprété comme la recherche d'une copie exacte d'un amplificateur particulier.

La démarche ToneLab consiste plutôt à identifier les caractéristiques sonores recherchées.

Dans le cadre de cette documentation, le territoire EVH est notamment associé à :

- une saturation importante ;
- une attaque franche ;
- une réponse dynamique ;
- des médiums présents ;
- un grave contrôlé ;
- une sensation de puissance ;
- une certaine agressivité ;
- une bonne interaction avec le jeu.

Le son doit pouvoir rester expressif même lorsque le niveau de saturation augmente.

---

# Le territoire sonore EVH

Le territoire EVH est particulièrement intéressant parce qu'il ne repose pas simplement sur une grande quantité de Gain.

Un son fortement saturé peut devenir :

- trop compressé ;
- trop lisse ;
- trop moderne ;
- trop dense.

Le territoire recherché nécessite au contraire de conserver une certaine réaction à l'attaque.

Le guitariste doit pouvoir influencer le résultat par :

- la force de son jeu ;
- le médiator ;
- le volume de la guitare ;
- la manière d'attaquer les cordes.

Cette dimension dynamique est donc fondamentale.

---

# Les principales caractéristiques recherchées

## Saturation

La saturation doit être suffisamment importante pour produire :

- sustain ;
- épaisseur ;
- puissance ;
- agressivité.

Mais elle ne doit pas nécessairement être maximale.

Un niveau de Gain légèrement inférieur peut parfois permettre de conserver davantage :

- d'attaque ;
- de dynamique ;
- de séparation.

---

## Médiums

Les médiums constituent un élément important du territoire.

Ils permettent de conserver :

- présence ;
- caractère ;
- articulation ;
- puissance perçue.

Un creusement excessif des médiums peut rendre le son plus spectaculaire seul mais moins efficace dans un mix.

---

## Attaque

L'attaque doit rester clairement perceptible.

Elle permet de conserver :

- précision ;
- agressivité ;
- articulation ;
- sensation de puissance.

Un son trop compressé perd une partie de cette sensation.

---

## Grave

Le grave doit être suffisamment présent pour produire une sensation de puissance.

Mais il doit rester suffisamment contrôlé pour ne pas masquer l'attaque.

Cette notion est particulièrement importante avec un cabinet capable de produire beaucoup de graves.

---

# Le Brunetti face au territoire EVH

Le Brunetti possède plusieurs caractéristiques qui peuvent permettre d'explorer ce territoire.

Deux canaux apparaissent particulièrement intéressants :

**Boost**

et

**XLead**

Leur comparaison est particulièrement pertinente parce qu'ils peuvent tous les deux produire des sons saturés tout en présentant des comportements différents.

---

# Le rôle du canal XLead

Le XLead constitue une base évidente pour rechercher un son EVH fortement saturé.

Il permet notamment :

- un niveau de Gain important ;
- une saturation dense ;
- une attaque agressive ;
- une forte présence ;
- une grande réserve de saturation.

Il peut donc être particulièrement intéressant lorsque l'objectif est un son EVH plus :

- puissant ;
- agressif ;
- dense ;
- moderne.

Cependant, il faudra veiller à ne pas augmenter inutilement le Gain.

Un excès de saturation peut éloigner le résultat du caractère dynamique recherché.

---

# Le rôle du canal Boost

Le Boost devient particulièrement intéressant dans ce territoire.

Son caractère :

- riche en harmoniques ;
- épais ;
- dynamique ;
- compact ;

peut être compatible avec une recherche de saturation importante tout en conservant davantage de réaction au jeu.

Le Boost pourrait donc constituer une base intéressante pour une approche EVH plus :

- ouverte ;
- dynamique ;
- organique ;
- expressive.

Cette hypothèse devra cependant être validée.

Il ne faut pas considérer :

> Boost = EVH

comme une conclusion.

Il faut plutôt considérer :

> **Boost = candidat à comparer sérieusement au XLead pour le territoire EVH.**

---

# Boost et XLead : une comparaison particulièrement intéressante

Le territoire EVH est probablement l'un des meilleurs endroits pour comparer directement les deux canaux.

## Boost

Hypothèse de comportement :

- dynamique ;
- riche en harmoniques ;
- épais ;
- réactif ;
- moins compressé.

## XLead

Hypothèse de comportement :

- plus saturé ;
- plus dense ;
- plus agressif ;
- plus précis ;
- plus moderne.

Le choix dépendra donc du profil EVH recherché.

Un son plus vintage ou plus ouvert pourrait favoriser le Boost.

Un son plus agressif ou plus moderne pourrait favoriser le XLead.

Cette distinction devra être testée avec des réglages à niveau de saturation comparable.

---

# L'importance de la dynamique

La dynamique est probablement le critère qui permettra de départager le plus clairement les deux canaux.

Un bon profil EVH doit réagir aux différences d'attaque.

Il faut notamment vérifier :

- jeu doux ;
- jeu normal ;
- attaque forte ;
- palm-mutes ;
- accords ;
- notes isolées.

Un réglage qui semble excellent lorsque l'on joue fort peut perdre beaucoup d'intérêt lorsque l'on joue doucement.

La dynamique devra donc être évaluée volontairement.

---

# L'importance de l'attaque

L'attaque doit rester présente même lorsque le Gain augmente.

Une attaque trop faible peut donner une sensation :

- molle ;
- compressée ;
- distante.

Une attaque trop forte peut au contraire rendre le son :

- agressif ;
- dur ;
- fatigant.

Le bon réglage devra donc conserver une attaque nette sans excès.

---

# Influence du Gain

Le Gain doit être considéré comme un paramètre permettant de déplacer progressivement le son.

Une première progression peut être envisagée :

### Gain faible

→ crunch / rock

### Gain moyen

→ hard rock / EVH ouvert

### Gain élevé

→ EVH fortement saturé

### Gain très élevé

→ saturation moderne

La dernière zone peut commencer à s'éloigner du territoire EVH recherché.

Il ne faut donc pas confondre :

> davantage de Gain

avec

> davantage de ressemblance.

---

# Influence des médiums

Les médiums contribuent fortement au caractère du son.

Ils permettent notamment :

- de conserver la présence ;
- de renforcer l'attaque ;
- de faire ressortir les notes ;
- de donner du caractère à la saturation.

Un réglage trop creusé peut rapprocher le son d'un territoire plus moderne et moins typé.

Pour un profil EVH, les médiums devront donc probablement rester suffisamment présents.

---

# Influence de Bass

Bass permet de construire la sensation de puissance.

Mais un excès de Bass peut :

- ralentir la réponse ;
- masquer l'attaque ;
- augmenter le flou ;
- rendre les palm-mutes moins précis.

Une première approche consiste donc à rechercher un grave équilibré avant d'ajouter de la profondeur avec Depth.

---

# Influence de Edge

Edge joue un rôle important dans la perception de l'attaque.

Une augmentation peut apporter :

- brillance ;
- présence ;
- agressivité ;
- attaque.

Mais un excès peut rapidement produire un son trop dur.

Le réglage devra donc être recherché en fonction de la guitare et du cabinet.

---

# Influence de Focus

Focus peut être utilisé pour modifier la sensation de :

- fermeté ;
- attaque ;
- contrôle ;
- précision.

Dans le territoire EVH, il faudra éviter de rechercher systématiquement le maximum de contrôle.

Une partie du caractère recherché repose justement sur une certaine ouverture.

Focus devra donc être comparé sur plusieurs positions.

---

# Influence de Depth

Depth peut apporter :

- profondeur ;
- poids ;
- ampleur ;
- sensation de grave.

Mais il faudra conserver une attaque suffisamment nette.

Un excès de Depth peut déplacer le profil vers une sensation plus moderne et massive.

Pour un profil EVH, Depth devra donc être utilisé avec modération.

---

# Le rôle du volume

Le volume réel de l'amplificateur peut modifier fortement la perception.

À faible volume :

- les graves peuvent sembler différents ;
- la saturation peut sembler plus compressée ;
- la dynamique peut être moins perceptible.

À volume plus important :

- les haut-parleurs réagissent davantage ;
- la sensation de puissance augmente ;
- la dynamique peut devenir plus évidente.

Il faudra donc éviter de conclure définitivement sur un profil sans préciser le contexte de volume.

---

# Le rôle de la guitare

La guitare constitue un facteur particulièrement important.

## Gibson Les Paul Classic DC

La Gibson peut apporter :

- épaisseur ;
- sustain ;
- densité ;
- médiums.

Elle peut donc favoriser un profil EVH plus épais.

---

## Gretsch John Gourley Broadkaster

La Gretsch peut favoriser :

- attaque ;
- articulation ;
- séparation ;
- dynamique.

Elle pourrait donc être particulièrement intéressante avec le Boost si celui-ci produit un son suffisamment épais.

La comparaison des deux guitares devra être intégrée aux expérimentations.

---

# Le rôle des pédales

Les pédales peuvent modifier considérablement le territoire obtenu.

Une pédale placée devant le Brunetti peut :

- pousser le préamplificateur ;
- modifier la réponse du grave ;
- renforcer certaines fréquences ;
- modifier l'attaque.

Il sera donc important de distinguer :

**profil de l'amplificateur**

et

**profil de l'amplificateur + pédales.**

---

# Le rôle de la Tube Screamer

La Tube Screamer peut notamment :

- resserrer les graves ;
- augmenter les médiums ;
- accentuer l'attaque ;
- augmenter le niveau d'entrée.

Cette combinaison peut être intéressante avec le XLead.

Elle peut également permettre de pousser le Boost dans une zone plus agressive.

Cependant, une utilisation excessive peut réduire la dynamique.

Pour le territoire EVH, cette question sera donc particulièrement intéressante :

> **la Tube Screamer améliore-t-elle le profil ou lui retire-t-elle une partie de son caractère dynamique ?**

Cette question devra être testée directement.

---

# Le rôle de l'égalisation

Le Mooer Graphic G et le MXR 6 Band EQ peuvent être utilisés pour affiner le profil.

Ils peuvent notamment permettre de :

- contrôler le grave ;
- renforcer les médiums ;
- modifier l'attaque ;
- adapter le son à la guitare.

Mais l'EQ devra être utilisé après avoir établi une base cohérente.

L'objectif n'est pas de fabriquer artificiellement un territoire EVH avec l'égaliseur.

L'objectif est de déterminer comment l'EQ peut optimiser un comportement déjà cohérent.

---

# Le rôle du cabinet

Le cabinet est particulièrement important pour ce type de profil.

Le 4×12 de référence possède plusieurs configurations possibles de haut-parleurs.

Chaque configuration peut modifier :

- attaque ;
- médiums ;
- grave ;
- projection ;
- sensation de saturation.

Le Thiele équipé du Celestion 15 pouces pourra également produire un comportement différent.

Il devra donc être considéré comme une configuration distincte.

---

# Différence entre territoire EVH et territoire Marshall

Les deux territoires présentent des points communs importants :

- médiums ;
- dynamique ;
- attaque ;
- saturation ;
- caractère britannique ou dérivé.

Mais ils ne sont pas identiques.

## Marshall

Tendance :

- saturation progressive ;
- médiums ;
- dynamique ;
- grain ;
- comportement plus ouvert.

## EVH

Tendance :

- saturation plus importante ;
- attaque plus agressive ;
- puissance ;
- dynamique ;
- densité.

Le territoire EVH peut donc être considéré comme une évolution vers davantage de gain et d'agressivité tout en conservant une partie de la dynamique recherchée dans le territoire Marshall.

---

# Différence entre territoire EVH et territoire Mesa

Le territoire EVH et le territoire Mesa peuvent également se recouvrir.

Mais leur comportement recherché diffère.

## EVH

On recherche davantage :

- dynamique ;
- attaque ;
- médiums ;
- interaction avec le jeu.

## Mesa

On recherche davantage :

- densité ;
- largeur ;
- puissance ;
- saturation ;
- grave.

Cette distinction est importante.

Un son très saturé et massif n'est pas automatiquement un son EVH.

# Ce que nous retenons

Le territoire EVH constitue probablement l'un des territoires les plus intéressants pour comparer le Boost et le XLead.

Le **Boost** pourrait être particulièrement pertinent lorsque l'on recherche :

- dynamique ;
- grain ;
- épaisseur ;
- réaction au jeu ;
- saturation ouverte.

Le **XLead** pourrait devenir plus intéressant lorsque l'on recherche :

- davantage de Gain ;
- davantage de densité ;
- davantage d'agressivité ;
- un caractère plus moderne.

Cette distinction reste une hypothèse.

Elle devra être vérifiée sur le matériel réel.

---

# Conclusion

Le territoire EVH occupe une position intermédiaire dans la cartographie ToneLab.

Il partage certains éléments avec Marshall :

- médiums ;
- dynamique ;
- attaque ;
- caractère organique.

Il partage également certains éléments avec Mesa :

- saturation ;
- puissance ;
- densité ;
- agressivité.

Mais il conserve une exigence particulière :

> **la saturation doit rester expressive.**

C'est précisément ce qui rend le Boost particulièrement intéressant.

Le XLead permettra probablement d'obtenir plus facilement un niveau de saturation important.

Le Boost pourrait cependant produire une sensation plus dynamique et plus organique.

La comparaison entre les deux canaux devra donc être menée à niveau de saturation comparable.

Les futurs essais devront notamment comparer :

1. Boost seul ;
2. XLead seul ;
3. Boost + Tube Screamer ;
4. XLead + Tube Screamer ;
5. différentes positions de Focus ;
6. différents niveaux de Gain ;
7. Gibson et Gretsch ;
8. différentes configurations du cabinet.

Cette méthode permettra de déterminer si le Boost constitue réellement une meilleure base pour certains profils EVH ou si le XLead reste supérieur dans toutes les configurations.
