# Introduction

Parmi toutes les comparaisons rencontrées au cours des recherches, celle avec Marshall est probablement l'une des plus importantes pour comprendre le territoire sonore du Brunetti XL R-EVO II.

De nombreux utilisateurs décrivent le Brunetti comme capable de produire des sonorités présentant certaines caractéristiques associées aux amplificateurs britanniques.

Cette proximité apparaît notamment lorsque :

- le Gain reste modéré ;
- les médiums sont suffisamment présents ;
- l'attaque reste perceptible ;
- la saturation conserve une certaine dynamique ;
- les graves restent maîtrisés.

D'autres réglages peuvent cependant conduire le Brunetti vers des territoires beaucoup plus modernes.

Cette apparente contradiction est importante.

Le Brunetti ne possède pas un unique caractère sonore.

Il dispose de plusieurs voicings capables de déplacer considérablement son comportement.

Le territoire Marshall doit donc être étudié non pas comme une simple équivalence entre deux amplificateurs, mais comme **une zone particulière de fonctionnement du Brunetti**.

---

# Que signifie réellement « son Marshall » ?

Le terme « Marshall » recouvre plusieurs générations et plusieurs comportements.

Il serait donc incorrect de chercher un unique réglage capable de représenter l'ensemble de la marque.

Pour ToneLab, plusieurs familles sont particulièrement intéressantes :

- JTM45 ;
- Plexi / Super Lead ;
- JCM800 ;
- Marshall hot-rodded ;
- Marshall moderne.

Ces familles partagent certaines caractéristiques générales mais présentent également des différences importantes.

Le terme « Marshall » utilisé dans cette documentation désigne donc principalement une **famille de comportements sonores**, et non un modèle précis.

---

# Les principales caractéristiques du territoire Marshall

Plusieurs caractéristiques reviennent régulièrement lorsque l'on décrit les amplificateurs Marshall recherchés dans le cadre du projet.

## Médiums présents

Les médiums constituent une composante essentielle.

Ils donnent au son :

- sa présence ;
- son caractère vocal ;
- sa capacité à rester audible dans un mix ;
- une partie importante de sa personnalité.

Un son Marshall ne doit donc pas nécessairement être extrêmement creusé dans les médiums.

---

## Réponse à l'attaque

La réponse à l'attaque constitue également un élément important.

Le son doit pouvoir réagir au jeu du guitariste.

Une attaque plus forte peut produire davantage de saturation et de présence.

Une attaque plus légère peut laisser apparaître un son plus propre ou plus ouvert.

Cette interaction entre le guitariste et l'amplificateur participe fortement à la sensation de dynamique.

---

## Saturation progressive

Le territoire Marshall recherché dans ToneLab n'est généralement pas basé sur une saturation extrêmement compressée.

La saturation peut apparaître progressivement lorsque :

- le Gain augmente ;
- le niveau d'entrée augmente ;
- la guitare attaque plus fortement ;
- une pédale pousse le préamplificateur.

Cette évolution constitue une différence importante avec certains territoires high-gain plus modernes.

---

## Grave maîtrisé

Le grave doit rester suffisamment présent pour conserver la puissance du son.

Mais un grave excessif peut rapidement rendre le son :

- flou ;
- lent ;
- moins précis ;
- moins lisible.

Le contrôle du grave est donc particulièrement important lorsque le Brunetti est utilisé avec un cabinet capable de produire beaucoup d'énergie dans cette zone.

---

# Le Brunetti face à ces caractéristiques

Le Brunetti possède plusieurs comportements compatibles avec cette famille sonore.

Mais il est important de distinguer :

> **une proximité de comportement**

et

> **une reproduction exacte d'un amplificateur Marshall.**

Le Brunetti conserve sa propre architecture et sa propre réponse.

Le but du ToneLab n'est donc pas de déclarer :

> « Le Brunetti est un Marshall. »

Le but est plutôt de déterminer :

> « Quelles configurations du Brunetti permettent d'entrer le plus efficacement dans le territoire sonore recherché ? »

Cette distinction sera conservée dans toutes les analyses suivantes.

---

# Le rôle du canal Boost

Le canal Boost mérite une attention particulière dans le territoire Marshall.

Il ne doit pas être considéré comme un simple canal de crunch situé entre le Clean et le XLead.

Son comportement est décrit comme :

- riche en harmoniques ;
- épais ;
- compact ;
- dynamique.

Ces caractéristiques peuvent être particulièrement intéressantes pour les zones du territoire Marshall dans lesquelles l'on recherche :

- du crunch ;
- de l'épaisseur ;
- de la dynamique ;
- des médiums présents ;
- une saturation organique.

Le Boost constitue donc une hypothèse particulièrement sérieuse pour les territoires :

- Plexi ;
- Super Lead ;
- hard rock ;
- certains JCM800 ;
- Marshall hot-rodded modéré.

Cela ne signifie pas que le Boost sera systématiquement supérieur au XLead.

Il signifie qu'il doit être **étudié comme une véritable alternative**.

---

# Le rôle du canal XLead

Le XLead reste également un candidat important.

Son architecture permet notamment d'obtenir :

- davantage de gain ;
- davantage d'agressivité ;
- une saturation plus dense ;
- une attaque plus incisive ;
- un caractère plus moderne lorsque les réglages sont poussés.

Il peut donc être particulièrement intéressant pour :

- Marshall fortement poussé ;
- JCM800 très saturé ;
- Marshall hot-rodded ;
- certains sons rock modernes inspirés du caractère britannique.

Le XLead ne doit toutefois pas être automatiquement choisi simplement parce qu'il dispose de davantage de gain.

Le niveau de saturation recherché n'est qu'un des critères.

Le caractère de la saturation est tout aussi important.

---

# Boost et XLead : deux approches possibles

La comparaison entre les deux canaux est probablement l'un des points les plus importants de cette étude.

Une première hypothèse peut être formulée :

**Boost :**

- plus organique ;
- plus épais ;
- plus dynamique ;
- davantage orienté crunch / overdrive.

**XLead :**

- plus incisif ;
- plus dense ;
- davantage orienté saturation ;
- plus adapté aux territoires modernes ou fortement poussés.

Cette distinction reste cependant une hypothèse de travail.

L'expérimentation devra déterminer :

- jusqu'où le Boost peut être poussé ;
- à partir de quel niveau le XLead devient plus pertinent ;
- si le Boost possède effectivement une meilleure réponse dans le territoire Plexi ;
- si le XLead permet une approche Marshall plus moderne ;
- si les deux canaux peuvent produire des profils similaires avec des comportements différents.

---

# Le Clean dans le territoire Marshall

Le Clean ne doit pas être totalement exclu.

Certaines sonorités associées à la famille Marshall reposent sur un amplificateur peu saturé dont la dynamique provient en partie :

- du niveau d'entrée ;
- du volume ;
- de l'attaque ;
- de la guitare.

Le Clean peut donc être intéressant pour explorer :

- clean chaud ;
- edge of breakup ;
- crunch très léger.

Cependant, pour les territoires Marshall plus fortement saturés recherchés dans ToneLab, le Boost et le XLead sont probablement des points de départ plus pertinents.

Cette hypothèse devra être vérifiée dans les essais.

---

# Les différentes générations de Marshall

## JTM45

Le JTM45 représente une approche relativement ouverte et dynamique.

Le territoire recherché peut comporter :

- moins de saturation ;
- davantage de respiration ;
- une réponse dynamique importante ;
- un grave plus ample ;
- une attaque relativement douce.

Le Boost pourrait constituer une base intéressante pour explorer cette zone.

---

## Plexi / Super Lead

Le territoire Plexi représente une zone particulièrement intéressante pour le Boost.

On recherche notamment :

- médiums présents ;
- saturation progressive ;
- dynamique importante ;
- attaque sensible au jeu ;
- puissance sans compression excessive.

Le Gain n'a donc pas nécessairement besoin d'être extrêmement élevé.

Le réglage du canal et la manière dont le signal entre dans le préamplificateur peuvent être déterminants.

---

## JCM800

Le JCM800 représente une évolution vers davantage de gain et d'agressivité.

Il conserve cependant une identité britannique fortement marquée.

Deux approches devront donc être comparées :

**Boost :**

recherche d'un JCM800 plus ouvert et dynamique.

**XLead :**

recherche d'un JCM800 plus poussé ou plus moderne.

Le résultat réel devra être déterminé expérimentalement.

---

## Marshall moderne et hot-rodded

Lorsque le gain augmente et que la réponse devient plus dense, le XLead devient progressivement plus intéressant.

Il peut alors permettre d'explorer des territoires proches :

- Marshall modifié ;
- hot-rodded ;
- rock moderne ;
- saturation britannique plus agressive.

Le Boost ne doit cependant pas être éliminé.

Une saturation moins compressée peut parfois donner une impression plus proche du caractère recherché, même si elle possède moins de gain.

---

# Influence du Gain

Le Gain est probablement l'un des paramètres qui déplace le plus fortement le territoire.

Une première progression peut être envisagée :

**Gain faible**

→ clean poussé / edge of breakup

**Gain modéré**

→ crunch / Plexi

**Gain moyen**

→ hard rock / JCM800

**Gain élevé**

→ Marshall hot-rodded / rock moderne

Cette progression n'est pas une règle absolue.

Elle dépend du canal utilisé.

Le même niveau de Gain ne produit pas nécessairement le même résultat sur le Boost et le XLead.

C'est précisément pour cette raison que les deux canaux doivent être comparés à plusieurs niveaux de Gain.

---

# Influence des médiums

Les médiums sont particulièrement importants dans cette recherche.

Une réduction excessive peut éloigner rapidement le son du territoire Marshall recherché.

À l'inverse, un renforcement excessif peut rendre le son :

- nasal ;
- agressif ;
- trop étroit ;
- difficile à intégrer dans certains mixes.

Le bon réglage devra donc être recherché en fonction :

- du canal ;
- de la guitare ;
- du cabinet ;
- du niveau sonore.

---

# Influence de Bass et Edge

## Bass

Un réglage de Bass trop élevé peut donner une impression de puissance immédiate.

Mais avec un cabinet capable de produire beaucoup de graves, cette approche peut rapidement devenir excessive.

Pour les sons Marshall, il sera donc intéressant de rechercher un grave :

- présent ;
- contrôlé ;
- suffisamment ferme.

---

## Edge

Edge joue un rôle important dans la quantité d'agressivité et de présence dans les hautes fréquences.

Un Edge trop élevé peut rendre le son :

- dur ;
- brillant ;
- agressif.

Un Edge trop faible peut au contraire :

- réduire l'attaque ;
- assombrir le son ;
- diminuer la présence.

La bonne position dépendra donc fortement du canal.

---

# Influence de Focus

Focus constitue une commande particulièrement intéressante pour la comparaison Boost / XLead.

Son action peut modifier la sensation de :

- densité ;
- précision ;
- fermeté ;
- attaque.

Pour un territoire Marshall traditionnel, un réglage trop poussé pourrait éloigner le son du comportement recherché.

Mais pour une approche Marshall moderne ou hot-rodded, une utilisation plus importante peut devenir intéressante.

Focus devra donc être étudié en fonction du territoire précis recherché.

---

# La dynamique comme élément déterminant

La dynamique constitue probablement l'un des critères les plus importants pour distinguer certaines approches Marshall d'un son high-gain plus moderne.

Deux réglages peuvent produire une quantité de saturation comparable tout en donnant des sensations très différentes.

Un réglage plus dynamique peut :

- réagir davantage à l'attaque ;
- permettre de nettoyer légèrement le son avec le volume de la guitare ;
- produire davantage de contraste entre jeu doux et jeu fort.

Le Boost devra donc être particulièrement étudié sur ce point.

Le XLead devra également être comparé à niveau de saturation comparable.

---

# Influence de la guitare

Le territoire Marshall ne peut pas être défini indépendamment de la guitare.

La Gibson Les Paul Classic DC et la Gretsch John Gourley Broadkaster ne produisent pas le même comportement dans le Brunetti.

La Gibson peut notamment favoriser :

- épaisseur ;
- densité ;
- sustain ;
- médiums.

La Gretsch peut davantage favoriser :

- attaque ;
- articulation ;
- séparation ;
- dynamique perceptible.

Ces tendances ne constituent cependant pas des règles absolues.

La comparaison devra être réalisée avec des réglages identiques avant de modifier les paramètres du Brunetti.

Cette méthode permettra de distinguer :

> **le caractère du réglage**

de

> **l'influence de la guitare.**

---

# Influence des pédales

Les pédales peuvent déplacer considérablement le territoire obtenu.

La Tube Screamer Analogman Silver Mod constitue notamment un outil particulièrement intéressant.

Placée avant le Brunetti, elle peut :

- augmenter le niveau d'entrée ;
- renforcer certaines fréquences médiums ;
- réduire la sensation de grave ;
- augmenter l'attaque ;
- pousser davantage le préamplificateur.

Cette combinaison devra être étudiée séparément.

Il serait incorrect d'attribuer au Boost ou au XLead un caractère qui provient en réalité de la combinaison avec la Tube Screamer.

Le Mooer Graphic G pourra également être utilisé pour explorer les modifications apportées au territoire Marshall.

Ces essais devront cependant être documentés comme des configurations différentes.

---

# Le rôle du cabinet

Le cabinet constitue une partie intégrante du résultat final.

Dans le cadre du ToneLab, le 4×12 utilisé par référence possède plusieurs configurations possibles de haut-parleurs.

Le choix du cabinet peut modifier :

- le grave ;
- les médiums ;
- l'attaque ;
- la projection ;
- la sensation de saturation.

Le territoire Marshall ne pourra donc pas être considéré comme totalement indépendant du cabinet.

Les essais devront conserver une configuration de référence avant de comparer différentes combinaisons de haut-parleurs.

# Hypothèses à tester

Plusieurs hypothèses deviennent particulièrement intéressantes.

## Hypothèse 1 — Le Boost est le meilleur point de départ pour le Plexi

Le comportement dynamique et riche en harmoniques du Boost pourrait être particulièrement adapté à cette zone.

**Statut : 🧪 À tester**

---

## Hypothèse 2 — Le Boost peut approcher le JCM800

Le Boost pourrait produire un territoire proche du JCM800 avec davantage de dynamique et moins de compression.

**Statut : 🧪 À tester**

---

## Hypothèse 3 — Le XLead devient progressivement plus pertinent lorsque le gain augmente

Cette hypothèse semble cohérente avec son caractère plus incisif et plus dense.

**Statut : ◐ Hypothèse forte, à valider**

---

## Hypothèse 4 — La Tube Screamer peut rapprocher le Boost d'un Marshall plus agressif

La pédale pourrait permettre de déplacer le Boost vers une zone plus serrée et plus agressive sans utiliser le XLead.

**Statut : 🧪 À tester**

---

## Hypothèse 5 — La guitare peut modifier le choix du canal

Un même territoire Marshall pourrait nécessiter le Boost avec une guitare et le XLead avec une autre.

**Statut : 🧪 À tester**

# Ce que nous retenons

Le territoire Marshall ne doit pas être associé automatiquement au XLead.

Le **Boost doit désormais être considéré comme un candidat majeur**, notamment pour les zones :

- Plexi ;
- Super Lead ;
- crunch ;
- hard rock ;
- certains JCM800.

Le XLead reste particulièrement intéressant lorsque le territoire recherché devient :

- plus dense ;
- plus agressif ;
- plus fortement saturé ;
- plus moderne.

Le Clean conserve un rôle dans les zones les moins saturées.

La véritable question du ToneLab devient donc :

> **Quel canal permet d'entrer le plus naturellement dans la zone Marshall recherchée ?**

et non :

> **Quel réglage du XLead ressemble à un Marshall ?**

Cette distinction constitue une évolution importante de notre méthode.

---

# Conclusion

Le territoire Marshall constitue probablement l'un des meilleurs exemples de la nécessité de comparer les trois canaux du Brunetti.

Le Boost semble particulièrement intéressant pour les zones où l'on recherche :

- dynamique ;
- richesse harmonique ;
- épaisseur ;
- médiums ;
- saturation progressive.

Le XLead semble davantage adapté lorsque l'on souhaite conserver une identité britannique tout en augmentant :

- le gain ;
- la densité ;
- l'agressivité ;
- la précision.

Le Clean peut quant à lui intervenir dans les zones les moins saturées.

Aucune de ces correspondances ne doit cependant être considérée comme définitivement validée avant expérimentation.

La prochaine étape sera donc de construire des essais permettant de comparer directement :

**Boost / XLead**

à niveau de saturation comparable et avec une configuration de référence constante.

C'est cette comparaison qui permettra de déterminer si le Boost constitue réellement la meilleure porte d'entrée vers le territoire Marshall ou s'il ne couvre qu'une partie de celui-ci.
