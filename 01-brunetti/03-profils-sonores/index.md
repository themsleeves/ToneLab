> *Ce chapitre constitue le passage de l'analyse théorique à la construction concrète des profils sonores ToneLab. Il définit une méthode reproductible permettant de transformer les caractéristiques du Brunetti, du matériel utilisé et du territoire sonore recherché en configurations documentées et testables.*

# Qu'est-ce qu'un profil sonore ?

Un profil sonore n'est pas simplement une liste de positions de potentiomètres.

Il décrit, lorsque cela est nécessaire, un ensemble cohérent comprenant :

* le canal utilisé ;
* les réglages de l'amplificateur ;
* la guitare utilisée ;
* les micros ;
* l'accordage ;
* les pédales utilisées ;
* l'ordre des pédales ;
* les réglages des pédales ;
* le cabinet ;
* le contexte d'utilisation ;
* le niveau de volume ;
* le rôle musical recherché.

L'objectif est de pouvoir retrouver un son sans devoir recommencer toute la recherche depuis zéro.

---

# Philosophie de construction

Les profils sont construits à partir de la connaissance acquise dans les chapitres précédents.

La méthode générale repose sur une progression contrôlée :

1. identifier le territoire sonore recherché ;
2. déterminer le canal de départ ;
3. choisir la guitare et les micros adaptés ;
4. définir une base d'amplification ;
5. ajuster le Gain ;
6. construire l'équilibre tonal ;
7. ajuster les paramètres de voicing ;
8. déterminer le rôle des pédales ;
9. vérifier le résultat avec le cabinet utilisé ;
10. documenter le réglage ;
11. comparer les variantes ;
12. tester et valider le profil.

Cette méthode permet d'éviter de chercher directement des réglages au hasard.

# Méthode générale de validation

Les différentes parties du chapitre définissent progressivement une méthode de validation.

Un profil devra idéalement être construit selon la séquence suivante :

1. définir précisément la référence musicale ;
2. identifier le territoire sonore ;
3. choisir le canal de départ ;
4. choisir la guitare ;
5. construire une base aussi simple que possible ;
6. ajuster le Gain ;
7. ajuster l'équilibre tonal ;
8. ajuster les paramètres de voicing ;
9. introduire éventuellement la Tube Screamer ;
10. introduire éventuellement l'égalisation ;
11. comparer plusieurs variantes ;
12. tester à différents niveaux de volume ;
13. vérifier le résultat dans le contexte musical ;
14. documenter le réglage retenu ;
15. attribuer un statut au profil.

Cette progression permet de conserver une relation claire entre les modifications effectuées et le résultat obtenu.

➡️ **[Voir la Partie 7 — Méthode générale de validation](part7.md)**

# Organisation des expérimentations

Le profil final ne doit pas effacer l'historique de sa construction.

Plusieurs essais peuvent être nécessaires avant d'obtenir un résultat satisfaisant.

Il est donc important de conserver :

* les réglages testés ;
* les configurations rejetées ;
* les variantes prometteuses ;
* les observations ;
* les comparaisons ;
* les conclusions intermédiaires ;
* le réglage finalement retenu.

La logique recommandée est :

> **1 expérimentation = 1 configuration documentée**

Un même profil peut donc posséder plusieurs essais successifs.

Par exemple :

QOTSA-001
QOTSA-002
QOTSA-003
QOTSA-004

➡️ **[Voir la Partie 8 — Organisation des expérimentations](part8.md)**

# Évolution vers l'application ToneLab

La méthode de construction des profils a progressivement fait apparaître le besoin d'un outil permettant de conserver les configurations expérimentées.

ToneLab répond à ce besoin.

L'application distingue désormais le **matériel**, décrit dans le catalogue, et les **configurations utilisées dans les tests**.

Cette architecture permet notamment de réutiliser les mêmes éléments matériels dans différentes expérimentations.

Le catalogue peut contenir :

* des amplificateurs ;
* des pédales ;
* des guitares ;
* des cabinets.

Les tests permettent ensuite de décrire la combinaison réellement utilisée et les réglages associés.

La documentation Markdown et ToneLab ont ainsi des rôles complémentaires :

> **ToneLab conserve les données de travail ; la documentation conserve les connaissances et les conclusions.**

➡️ **[Voir la Partie 9 — Évolution vers l'application ToneLab](part9.md)**

# Conclusion du chapitre

Le Chapitre 03 transforme les connaissances acquises sur le Brunetti XL R-EVO II en une méthode concrète de construction de profils sonores.

La démarche repose désormais sur plusieurs principes :

* partir d'un objectif sonore clairement défini ;
* choisir progressivement le matériel et le canal adaptés ;
* limiter les variables modifiées simultanément ;
* distinguer les expérimentations des profils retenus ;
* conserver les essais précédents ;
* comparer les configurations ;
* valider les résultats dans leur contexte ;
* documenter les conclusions ;
* utiliser ToneLab pour conserver les données détaillées.

Le résultat recherché n'est pas un ensemble figé de presets.

Il s'agit d'une **méthode de recherche sonore reproductible**, capable d'évoluer avec le matériel, les expérimentations et les connaissances acquises.
