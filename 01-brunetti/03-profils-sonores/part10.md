<a id="part10-analyse"></a>

## 2. De l'analyse à l'expérimentation

Les premières parties de ce chapitre ont permis de définir une méthode permettant de passer de la connaissance du Brunetti à la construction de profils sonores.

Le travail ne consiste pas à rechercher un réglage universel.

Il consiste à partir d'un territoire sonore, à choisir une configuration cohérente et à l'ajuster progressivement jusqu'à obtenir un résultat satisfaisant.

Les profils musicaux constituent l'application concrète de cette démarche.

---

<a id="part10-methode"></a>

## 3. Une méthode reproductible

La méthode développée repose sur plusieurs principes simples :

* partir d'une intention sonore clairement définie ;
* limiter le nombre de variables modifiées simultanément ;
* construire d'abord une base cohérente ;
* utiliser les pédales et l'égalisation lorsque leur intervention est réellement nécessaire ;
* comparer les variantes ;
* conserver les expérimentations ;
* tester les configurations dans leur contexte musical ;
* documenter les résultats.

Cette organisation permet de transformer une recherche subjective en démarche suffisamment structurée pour être reproduite.

---

<a id="part10-materiel"></a>

## 4. Des profils construits autour du matériel réel

Les profils étudiés dans ce chapitre ne sont pas des reproductions théoriques de configurations d'artistes.

Ils sont construits à partir du matériel réellement disponible.

Le résultat dépend donc de l'ensemble de la chaîne :

* guitare ;
* micros ;
* accordage ;
* pédales ;
* amplificateur ;
* cabinet ;
* réglages.

Le Brunetti XL R-EVO II constitue actuellement le centre de cette chaîne.

Ses différents canaux, notamment le Clean, le Boost et le XLead, permettent d'explorer plusieurs zones de fonctionnement sans devoir changer d'amplificateur.

---

<a id="part10-experimentations"></a>

## 5. Le rôle des expérimentations

Un profil n'est pas nécessairement obtenu dès le premier essai.

Plusieurs configurations peuvent être nécessaires pour explorer une même direction sonore.

C'est pourquoi les expérimentations doivent être conservées plutôt que remplacées systématiquement.

Cette approche permet de comparer les résultats et de comprendre progressivement quelles modifications améliorent réellement le profil recherché.

La distinction entre **test** et **profil retenu** permet ainsi de conserver l'historique sans confondre recherche et résultat final.

---

<a id="part10-tonelab"></a>

## 6. Le rôle de ToneLab

ToneLab prolonge cette méthode en fournissant un outil permettant d'enregistrer les configurations et les résultats des expérimentations.

L'application permet notamment de gérer :

* le catalogue de matériel ;
* les amplificateurs ;
* les pédales ;
* les guitares ;
* les cabinets ;
* les configurations de test ;
* les réglages associés ;
* les observations et les statuts.

Son architecture est désormais suffisamment générique pour évoluer au-delà du matériel actuellement utilisé.

Elle reste cependant, dans le cadre de ce projet, principalement exploitée autour du Brunetti XL R-EVO II.

---

<a id="part10-evolution"></a>

## 7. Une démarche appelée à évoluer

La construction des profils sonores n'est pas considérée comme définitivement terminée.

De nouveaux essais pourront conduire à :

* modifier certains profils ;
* créer de nouvelles variantes ;
* retenir de nouvelles configurations ;
* abandonner certaines pistes ;
* intégrer de nouveaux éléments matériels ;
* faire évoluer ToneLab.

La documentation doit donc être considérée comme un état structuré des connaissances acquises, et non comme une liste figée de réglages définitifs.

---

<a id="part10-a-retenir"></a>

## 8. À retenir

Le Chapitre 03 établit la méthode utilisée pour construire les profils sonores du projet ToneLab.

Cette méthode repose sur une idée centrale :

> **un profil sonore est le résultat documenté d'une recherche menée à partir d'un matériel réel, d'une intention sonore et d'une série d'expérimentations contrôlées.**

Le Brunetti XL R-EVO II fournit actuellement la base matérielle du travail.

Les guitares, cabinets et pédales permettent ensuite d'adapter cette base aux différents territoires sonores recherchés.

Les expérimentations permettent de progresser vers des configurations reproductibles.

Enfin, ToneLab permet de conserver et d'organiser ces recherches afin qu'elles puissent être retrouvées, comparées et réutilisées.

Le chapitre constitue ainsi le passage entre :

> **comprendre le Brunetti → construire des profils → expérimenter → valider → conserver les résultats.**
