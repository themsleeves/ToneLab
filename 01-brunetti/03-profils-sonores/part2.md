<a id="part2-introduction"></a>

## 1. Introduction

Avant de construire des profils inspirés d'un artiste, d'un morceau ou d'un amplificateur particulier, il est nécessaire de disposer de quelques références simples.

Ces profils ont pour objectif de caractériser le comportement du Brunetti XL R-EVO II dans différentes zones de fonctionnement.

Ils ne cherchent donc pas encore à reproduire un son précis.

Ils servent plutôt de **points de départ** pour les recherches ultérieures.

Les principales références retenues sont :

- Clean ;
- Crunch ;
- Rock ;
- High Gain ;
- son massif ;
- son articulé.

---

<a id="part2-pourquoi"></a>

## 2. Pourquoi commencer par des profils de référence ?

Un profil inspiré d'un artiste peut dépendre de nombreux éléments.

Il peut être difficile de déterminer si le résultat obtenu vient :

- du canal ;
- du niveau de Gain ;
- de l'égalisation ;
- de la guitare ;
- des micros ;
- d'une pédale ;
- du cabinet ;
- ou de l'interaction entre plusieurs de ces éléments.

Les profils de référence permettent de réduire cette complexité.

Ils constituent une base connue à partir de laquelle les profils plus spécifiques pourront être construits.

---

<a id="part2-clean"></a>

## 3. Profil de référence Clean

### Objectif

Le profil Clean doit permettre d'observer le comportement du Brunetti avec un minimum de saturation provenant du préamplificateur.

L'objectif est d'obtenir :

- une attaque lisible ;
- une réponse dynamique ;
- une bonne séparation des notes ;
- une base suffisamment neutre pour évaluer les guitares et les effets.

### Canal

**Clean**

### Méthode de construction

Le Gain doit être réglé de manière à conserver la propreté recherchée tout en permettant de conserver une réponse dynamique au jeu.

L'égalisation doit ensuite être équilibrée sans chercher immédiatement une couleur musicale particulière.

L'objectif est avant tout de disposer d'une référence.

### Utilité

Ce profil servira notamment à :

- comparer les guitares ;
- comparer les micros ;
- tester les effets ;
- observer l'influence des réglages de tonalité ;
- disposer d'une base neutre pour les recherches futures.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

---

<a id="part2-crunch"></a>

## 4. Profil de référence Crunch

### Objectif

Le profil Crunch doit représenter la zone dans laquelle le Brunetti commence à produire une saturation clairement perceptible tout en conservant une dynamique importante.

Le résultat recherché doit rester suffisamment ouvert pour permettre au jeu du guitariste et au volume de la guitare d'influencer le niveau de saturation perçu.

### Canal

Le **Boost** constitue le premier point de départ logique pour cette recherche.

### Caractéristiques recherchées

- saturation modérée ;
- attaque présente ;
- médiums suffisamment lisibles ;
- dynamique importante ;
- capacité à passer d'un son plus propre à un son plus saturé en fonction du jeu.

### Utilité

Le profil Crunch constituera notamment une référence pour les futures recherches :

- Marshall ;
- rock classique ;
- rock alternatif ;
- sons dynamiques ;
- utilisation de la Tube Screamer comme élément de poussée du préamplificateur.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

---

<a id="part2-rock"></a>

## 5. Profil de référence Rock

### Objectif

Le profil Rock constitue une étape intermédiaire entre le Crunch et le High Gain.

Il doit fournir davantage de densité et de saturation tout en conservant suffisamment de définition pour les accords et les riffs.

### Canal

Le **Boost** constitue un point de départ privilégié.

Le XLead pourra également être testé afin de déterminer lequel permet d'obtenir le comportement recherché avec notre configuration.

### Caractéristiques recherchées

- saturation plus importante que sur le profil Crunch ;
- médiums présents ;
- bonne attaque ;
- grave suffisamment ferme ;
- définition conservée dans les accords.

### Utilité

Ce profil servira de référence pour de nombreuses recherches musicales.

Il pourra notamment constituer une base pour les territoires :

- rock alternatif ;
- hard rock ;
- stoner ;
- post-hardcore ;
- rock moderne.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

---

<a id="part2-high-gain"></a>

## 6. Profil de référence High Gain

### Objectif

Le profil High Gain doit permettre d'explorer la zone de saturation importante du Brunetti.

L'objectif n'est pas de rechercher immédiatement le maximum de gain disponible.

Il s'agit plutôt de déterminer à partir de quel niveau le son devient suffisamment dense tout en conservant une définition exploitable.

### Canal

**XLead**

### Caractéristiques recherchées

- saturation importante ;
- sustain ;
- densité ;
- attaque suffisamment précise ;
- grave contrôlé ;
- médiums permettant de conserver la lisibilité.

### Point important

Le niveau de Gain devra être déterminé en fonction du résultat réellement obtenu.

Une quantité maximale de gain n'est pas nécessairement synonyme d'un meilleur profil High Gain.

Le profil devra privilégier la combinaison entre :

- saturation ;
- définition ;
- dynamique ;
- articulation.

### Utilité

Ce profil constituera la base des recherches ultérieures vers :

- Mesa Boogie ;
- Diezel ;
- EVH ;
- metal ;
- high gain moderne.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

---

<a id="part2-massif"></a>

## 7. Profil de référence Massif

### Objectif

Le profil Massif cherche à caractériser la capacité du Brunetti à produire un son dense, large et physiquement imposant.

Il ne s'agit pas simplement d'ajouter davantage de Gain.

La sensation de masse dépend également de :

- l'équilibre du grave ;
- la présence des médiums ;
- la réponse de la section de puissance ;
- la guitare ;
- les micros ;
- le cabinet.

### Canal

**XLead**

### Caractéristiques recherchées

- forte densité ;
- grave ferme ;
- sustain important ;
- sensation de puissance ;
- présence suffisante pour éviter un son brouillon.

### Point de vigilance

Un excès de grave peut donner une impression de puissance lorsque le son est joué seul, mais devenir problématique dans un contexte de groupe.

Le profil Massif devra donc être évalué également sur sa capacité à conserver sa définition.

### Utilité

Ce profil constituera notamment une référence pour les recherches :

- stoner ;
- heavy rock ;
- QOTSA ;
- Kyuss ;
- Hermano ;
- sons modernes à forte densité.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

---

<a id="part2-articule"></a>

## 8. Profil de référence Articulé

### Objectif

Le profil Articulé constitue le complément du profil Massif.

L'objectif est de rechercher un son permettant de distinguer clairement :

- les attaques ;
- les notes ;
- les accords ;
- les différentes cordes.

Le but n'est donc pas de rechercher le maximum de saturation ou de puissance.

### Canal

Le **XLead** constitue un point de départ possible.

Le **Boost** devra également être comparé afin de déterminer quelle architecture permet d'obtenir le meilleur compromis entre saturation et définition.

### Caractéristiques recherchées

- attaque précise ;
- séparation des notes ;
- grave contrôlé ;
- médiums lisibles ;
- saturation suffisamment importante ;
- faible tendance à l'écrasement du jeu.

### Utilité

Ce profil sera particulièrement intéressant pour les recherches orientées vers :

- Diezel ;
- EVH ;
- rock moderne ;
- riffs précis ;
- accords complexes ;
- sons nécessitant une forte séparation des notes.

### Statut

🧪 **Profil de référence à construire et valider sur le matériel.**

<a id="part2-comparaison"></a>

## 9. Comparaison des profils

Les six profils ne doivent pas être considérés comme six réglages définitifs.

Ils représentent six **zones de recherche**.

| Profil | Objectif principal | Canal de départ |
|---|---|---|
| Clean | Dynamique et clarté | Clean |
| Crunch | Saturation dynamique | Boost |
| Rock | Densité et polyvalence | Boost |
| High Gain | Saturation importante | XLead |
| Massif | Densité et puissance perçue | XLead |
| Articulé | Définition et séparation | XLead / Boost |

Cette première cartographie permet de disposer d'une base commune avant de rechercher des profils plus spécialisés.

---

<a id="part2-gain"></a>

## 10. Le rôle du Gain

Le Gain constitue l'un des paramètres les plus importants pour passer progressivement d'un profil à l'autre.

Cependant, les profils ne doivent pas être définis uniquement par leur quantité de Gain.

Deux réglages présentant un niveau de saturation similaire peuvent avoir des comportements très différents selon :

- l'égalisation ;
- le voicing ;
- la guitare ;
- les micros ;
- les pédales ;
- le cabinet.

Le Gain doit donc être considéré comme l'un des paramètres d'un système complet.

---

<a id="part2-egalisation"></a>

## 11. Le rôle de l'égalisation

L'égalisation permet ensuite d'orienter chaque profil.

Les objectifs peuvent être différents selon le profil.

### Clean

Rechercher l'équilibre et la clarté.

### Crunch

Conserver les médiums et la dynamique.

### Rock

Obtenir suffisamment de densité sans perdre l'attaque.

### High Gain

Contrôler le grave et préserver la définition.

### Massif

Renforcer la sensation de densité sans transformer le son en bouillie.

### Articulé

Favoriser la séparation et la lisibilité.

Ces descriptions constituent des objectifs de recherche et non des valeurs fixes.

---

<a id="part2-guitare"></a>

## 12. Le rôle de la guitare

Les profils de référence devront être testés avec les guitares de référence du ToneLab.

La **Gibson Les Paul Classic DC** et la **Gretsch John Gourley Broadkaster** ne produisent pas exactement le même signal.

La Les Paul peut constituer une base particulièrement intéressante pour les profils recherchant :

- épaisseur ;
- sustain ;
- densité ;
- médiums.

La Gretsch peut être particulièrement intéressante pour les profils recherchant :

- attaque ;
- séparation ;
- clarté ;
- articulation.

Ces observations devront toutefois être confirmées profil par profil.

Elles ne doivent pas être transformées en règles absolues.

---

<a id="part2-pedales"></a>

## 13. Le rôle des pédales

Les profils de référence doivent dans un premier temps être construits avec une chaîne aussi simple que possible.

Cela permet de caractériser le comportement propre de l'amplificateur.

Les pédales pourront ensuite être ajoutées progressivement afin de déterminer leur influence.

Cette méthode est particulièrement importante pour la Tube Screamer et le MXR 6 Band EQ.

Ils pourront être utilisés ultérieurement comme outils permettant d'orienter un profil vers un territoire sonore particulier.

---

<a id="part2-presets"></a>

## 14. Les profils de référence ne sont pas encore des presets définitifs

Il est important de conserver cette distinction.

Un profil de référence décrit une **direction sonore**.

Un preset définitif doit, lui, fournir un réglage suffisamment précis pour être reproduit immédiatement.

Les profils de cette partie servent donc principalement à :

- comprendre le comportement du Brunetti ;
- établir des points de comparaison ;
- préparer les recherches plus spécialisées ;
- identifier les paramètres les plus importants.

Les valeurs définitives seront documentées lorsque les réglages auront été réellement testés et validés.

---

<a id="part2-validation"></a>

## 15. Méthode de validation

Chaque profil devra être validé progressivement.

La validation devra idéalement comprendre :

1. un réglage initial ;
2. une écoute avec la guitare de référence ;
3. une comparaison avec les autres profils ;
4. un test à différents niveaux de volume ;
5. un test avec et sans les pédales concernées ;
6. une vérification dans le contexte musical prévu.

Un profil ne sera considéré comme réellement établi qu'après cette phase de validation.

---

<a id="part2-apprentissage"></a>

## 16. Ce que ces profils doivent nous apprendre

L'objectif principal de cette partie n'est finalement pas de produire six bons sons.

Il est de comprendre comment le Brunetti se comporte lorsque nous passons progressivement :

- du propre au saturé ;
- du léger au dense ;
- du massif à l'articulé ;
- du comportement dynamique au comportement plus compressé.

Cette connaissance permettra ensuite d'aborder les territoires sonores spécifiques avec beaucoup plus de précision.

---

<a id="part2-a-retenir"></a>

## 17. À retenir

Les profils de référence constituent la base pratique du ToneLab.

Ils permettent de définir six zones principales :

- **Clean** — clarté et dynamique ;
- **Crunch** — saturation dynamique ;
- **Rock** — densité polyvalente ;
- **High Gain** — saturation importante ;
- **Massif** — densité et puissance perçue ;
- **Articulé** — définition et séparation.

Ils ne constituent pas encore des presets définitifs.

Ils servent de points de départ pour les chapitres suivants et devront être progressivement testés, ajustés et validés sur le matériel de référence.
