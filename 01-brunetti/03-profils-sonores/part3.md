<a id="part3-introduction"></a>

## 1. Introduction

Les profils de référence permettent de comprendre les grandes zones de fonctionnement du Brunetti.

L'étape suivante consiste à rapprocher ces zones de différents **territoires sonores**.

Un territoire sonore ne correspond pas à un réglage unique.

Il représente plutôt une famille de sons partageant certaines caractéristiques communes.

Cette approche permet de rechercher progressivement un son correspondant à une esthétique musicale sans réduire cette recherche à une simple liste de réglages.

---

<a id="part3-definition"></a>

## 2. Qu'est-ce qu'un territoire sonore ?

Un territoire sonore peut être défini comme une combinaison de plusieurs caractéristiques :

- niveau de saturation ;
- quantité de médiums ;
- comportement du grave ;
- présence de l'aigu ;
- dynamique ;
- compression ;
- attaque ;
- définition ;
- sensation de largeur et de densité.

Un territoire peut également être associé à une famille d'amplificateurs ou à une esthétique musicale.

Par exemple :

- Marshall ;
- Mesa Boogie ;
- Diezel ;
- EVH ;
- Stoner ;
- Rock alternatif ;
- Post-Hardcore ;
- Metal.

Ces catégories ne doivent cependant pas être considérées comme parfaitement séparées.

Elles peuvent se chevaucher.

---

<a id="part3-pourquoi"></a>

## 3. Pourquoi travailler par territoires ?

Chercher directement à reproduire le son d'un groupe ou d'un guitariste peut conduire à une approche trop spécifique.

Il est généralement plus utile de commencer par identifier le territoire sonore correspondant.

Par exemple, avant de rechercher un son particulier inspiré de **Foo Fighters**, il peut être intéressant d'identifier :

- la quantité de gain ;
- le niveau de médiums ;
- la réponse du grave ;
- la dynamique ;
- le type de saturation ;
- la place de la guitare dans le mix.

Le territoire constitue donc une étape intermédiaire entre le profil de référence et le preset final.

---

<a id="part3-clean"></a>

## 4. Territoire Clean

Le territoire Clean constitue la base de référence de l'amplificateur.

Il privilégie :

- la clarté ;
- la dynamique ;
- l'attaque ;
- la séparation des notes ;
- la réponse naturelle de la guitare.

Il peut ensuite être orienté vers différents styles grâce aux effets et à l'égalisation.

Le Clean peut ainsi servir de base pour :

- rock ;
- pop-rock ;
- ambient ;
- funk ;
- passages dynamiques.

Il constitue également une référence importante pour comparer les guitares et les micros.

---

<a id="part3-crunch-rock"></a>

## 5. Territoire Crunch / Rock

Le territoire Crunch / Rock se situe entre le Clean et le High Gain.

Il privilégie généralement :

- une saturation modérée ;
- une attaque conservée ;
- des médiums présents ;
- une bonne dynamique ;
- une réponse sensible au jeu.

Cette zone constitue un point de départ particulièrement polyvalent.

Elle peut être utilisée pour :

- rock classique ;
- rock alternatif ;
- hard rock ;
- post-grunge ;
- certaines approches de punk rock.

Le niveau de Gain peut être augmenté progressivement jusqu'à atteindre une saturation plus dense.

---

<a id="part3-marshall"></a>

## 6. Territoire Marshall

Le territoire Marshall constitue une référence importante pour le ToneLab.

Il est généralement associé à :

- des médiums présents ;
- une attaque franche ;
- un grave relativement contrôlé ;
- une saturation progressive ;
- une forte dynamique.

Le Brunetti peut être orienté vers ce territoire en exploitant notamment le canal **Boost** avec une quantité de Gain adaptée.

Le résultat recherché n'est pas nécessairement une reproduction exacte d'un Marshall.

L'objectif est plutôt de retrouver une sensation comparable dans :

- l'équilibre spectral ;
- la dynamique ;
- la réaction au jeu ;
- la manière dont les médiums occupent l'espace.

Ce territoire sera particulièrement utile pour les recherches liées au rock et au hard rock.

---

<a id="part3-mesa"></a>

## 7. Territoire Mesa Boogie

Le territoire Mesa Boogie correspond à une approche plus dense et plus saturée.

Il peut notamment être associé à :

- un grave plus imposant ;
- une saturation plus importante ;
- une forte densité ;
- une attaque plus agressive ;
- une réponse adaptée aux riffs lourds.

Le canal **XLead** constitue naturellement un point de départ important pour cette recherche.

L'objectif n'est toutefois pas de transformer le Brunetti en copie d'un Mesa Boogie.

Il s'agit d'identifier les caractéristiques communes permettant d'approcher cette famille sonore.

Ce territoire sera particulièrement intéressant pour les recherches autour du :

- heavy rock ;
- metal ;
- rock moderne ;
- stoner plus lourd.

---

<a id="part3-diezel"></a>

## 8. Territoire Diezel

Le territoire Diezel représente une autre approche du High Gain.

Il privilégie généralement :

- une forte définition ;
- un grave ferme ;
- une saturation dense ;
- une attaque précise ;
- une grande capacité à conserver la séparation des notes.

La quantité de Gain n'est donc pas le seul élément important.

Le contrôle du grave et l'équilibre général du spectre sont essentiels.

Le Brunetti pourra être étudié dans cette direction principalement avec le XLead.

Ce territoire sera particulièrement utile pour les recherches concernant :

- les riffs modernes ;
- les accords complexes ;
- le High Gain précis ;
- les sons nécessitant beaucoup de définition.

---

<a id="part3-evh"></a>

## 9. Territoire EVH

Le territoire EVH se situe dans une zone de saturation importante tout en conservant une forte présence dans les médiums.

Il peut notamment rechercher :

- une attaque importante ;
- une saturation expressive ;
- des médiums présents ;
- un grave suffisamment ferme ;
- une bonne réaction au jeu.

Le XLead constitue un point de départ logique pour cette recherche.

La difficulté consiste à conserver l'agressivité du son sans obtenir une saturation excessivement compressée.

Ce territoire sera notamment intéressant pour les recherches orientées vers le hard rock et le metal.

---

<a id="part3-stoner"></a>

## 10. Territoire Stoner

Le territoire Stoner constitue une zone particulièrement importante pour le ToneLab.

Il privilégie généralement :

- une forte densité ;
- un grave important ;
- des médiums épais ;
- une saturation importante ;
- une sensation de puissance ;
- une certaine épaisseur dans le son.

Le gain ne doit cependant pas nécessairement être poussé au maximum.

Une partie importante du caractère Stoner peut provenir de l'équilibre entre :

- saturation ;
- grave ;
- médiums ;
- volume ;
- guitare ;
- cabinet.

Ce territoire sera particulièrement pertinent pour les recherches autour de :

- Kyuss ;
- QOTSA ;
- Hermano ;
- Stoner Rock.

---

<a id="part3-alternatif"></a>

## 11. Territoire Rock alternatif

Le Rock alternatif constitue une catégorie très large.

Il peut couvrir des sons allant du Crunch relativement ouvert jusqu'au High Gain.

Ses caractéristiques peuvent inclure :

- forte présence des médiums ;
- saturation expressive ;
- dynamique ;
- attaque importante ;
- capacité à fonctionner avec des riffs et des accords.

Le Brunetti est particulièrement intéressant pour cette recherche car ses différents canaux permettent d'explorer plusieurs niveaux de saturation sans changer complètement d'amplificateur.

Ce territoire sera notamment important pour les recherches liées à :

- Foo Fighters ;
- Rage Against The Machine ;
- Queens of the Stone Age ;
- Biffy Clyro.

---

<a id="part3-post-hardcore"></a>

## 12. Territoire Post-Hardcore

Le Post-Hardcore peut demander une combinaison particulière entre agressivité et définition.

Les caractéristiques recherchées peuvent inclure :

- attaque forte ;
- médiums présents ;
- saturation importante ;
- dynamique conservée ;
- bonne lisibilité des riffs.

Le Brunetti pourra être étudié dans cette direction à partir du Boost ou du XLead selon le niveau de saturation recherché.

Le réglage devra également tenir compte du contexte de groupe.

Un son extrêmement dense seul peut devenir trop massif lorsqu'il est associé à une basse et une batterie.

---

<a id="part3-metal"></a>

## 13. Territoire Metal / High Gain

Le territoire Metal représente la zone où la saturation et la précision deviennent particulièrement importantes.

Les priorités sont généralement :

- gain élevé ;
- grave ferme ;
- attaque précise ;
- définition ;
- contrôle de la compression ;
- séparation des notes.

Le XLead constitue la base naturelle de cette recherche.

Cependant, le réglage devra être construit autour de la définition plutôt que de la simple quantité de Gain.

L'objectif est d'obtenir un son capable de rester lisible pendant les riffs rapides et les passages fortement saturés.

---

<a id="part3-copies"></a>

## 14. Les territoires ne sont pas des copies

Un territoire sonore ne doit jamais être interprété comme une obligation de reproduire exactement un amplificateur ou un artiste.

Le Brunetti possède son propre comportement.

L'objectif du ToneLab est donc de déterminer :

> quelles caractéristiques du territoire peuvent être obtenues avec le Brunetti ?

Cette distinction est importante.

Un preset peut être considéré comme réussi même s'il ne reproduit pas exactement le matériel original, dès lors qu'il produit le comportement sonore recherché dans le contexte musical prévu.

---

<a id="part3-transition"></a>

## 15. Passage d'un territoire à l'autre

Les territoires sonores ne sont pas séparés par des frontières strictes.

Il existe de nombreuses zones intermédiaires.

Par exemple :

**Crunch → Rock → Marshall → Mesa Boogie → High Gain**

ou :

**Rock → Stoner → High Gain → Diezel**

Le ToneLab doit permettre de comprendre ces transitions.

Cela sera particulièrement utile lorsque plusieurs sons doivent être utilisés au cours d'un même morceau ou d'un même concert.

---

<a id="part3-materiel"></a>

## 16. Relation entre territoire et matériel

Le territoire sonore dépend également du matériel utilisé autour du Brunetti.

Les principaux éléments à prendre en compte sont :

- guitare ;
- micros ;
- accordage ;
- pédales ;
- câblage ;
- boucle d'effets ;
- cabinet ;
- haut-parleurs ;
- volume de fonctionnement.

Un même réglage du Brunetti peut donc produire une impression différente selon la configuration.

Les presets du ToneLab devront toujours préciser leur contexte matériel lorsque celui-ci influence significativement le résultat.

---

<a id="part3-a-retenir"></a>

## 17. À retenir

Les territoires sonores constituent une étape intermédiaire entre les profils de référence et les presets définitifs.

Les principales familles étudiées sont :

- Clean ;
- Crunch / Rock ;
- Marshall ;
- Mesa Boogie ;
- Diezel ;
- EVH ;
- Stoner ;
- Rock alternatif ;
- Post-Hardcore ;
- Metal / High Gain.

Le but n'est pas de transformer le Brunetti en une copie d'un autre amplificateur.

Il s'agit d'identifier les caractéristiques sonores recherchées et de déterminer comment les obtenir avec notre configuration.

Les parties suivantes pourront donc s'appuyer sur cette cartographie pour construire des profils plus précis et, progressivement, des presets réellement exploitables.
