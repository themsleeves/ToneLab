# Volume I

# Brunetti XL R-EVO II

> **Comprendre l'amplificateur avant de chercher un son.**

---

# Présentation

Ce volume est consacré exclusivement au **Brunetti XL R-EVO II**.

L'objectif n'est pas d'apprendre quelques réglages, mais de comprendre la philosophie de conception de cet amplificateur afin de pouvoir construire volontairement différents profils sonores.

Les analyses reposent sur :

* la documentation officielle ;
* les informations communiquées par Brunetti ;
* les retours d'utilisateurs expérimentés ;
* les recherches du projet ToneLab ;
* les expérimentations réalisées sur le matériel de référence.
